วิธีอ่านรายงาน · How to read
  • Stock = ตู้เปล่าที่อยู่ในลานตอนนี้ · Overdue pickup = booking ที่เลยวันนัดแล้วแต่ยังไม่ได้รับตู้ (หักออกก่อน)
  • ช่อง WK: ตัวเลขใหญ่ = ตู้คงเหลือ (AV balance) หลังหัก booking ของสัปดาห์นั้นและสัปดาห์ก่อนหน้าทั้งหมด · ตัวเล็ก = จำนวน booking ของสัปดาห์นั้น
  • ▼ สีแดง = ตู้คงเหลือติดลบ คือตู้ไม่พอรับ booking
  • Trend = เส้นแนวโน้มของตู้คงเหลือ จากวันนี้ถึงปลาย 4 สัปดาห์ (เส้นประ = ศูนย์)
  • WK1 รวม booking ตั้งแต่วันนี้ถึงวันเสาร์ของสัปดาห์นี้
Stock = empty containers in yard now (snapshot). Booking = pickups by TRAN DT. AV balance = stock − overdue pickup − cumulative bookings through each week. Generated from 2026-10-15 STAYING + booking exports.
